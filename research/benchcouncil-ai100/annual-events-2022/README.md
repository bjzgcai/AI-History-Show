# AI100 2022 selected-event research

This directory contains event-specific research and explainer sources for the ten 2022 achievements retained by `bench-council-ai100-2022-2023`.

Each retained event may own:

- one research JSON file;
- one event-local SVG source;
- referenced images under the append-only `resources/` tree;
- one complete Archive event bundle.

Update the corresponding Archive event bundle directly. Then run `npm run validate:archive`, `npm run audit:event-figure-rules`, `npm run audit:ai100-annual`, `npm run generate`, the AI100 context and quiz validators, `npm run lint`, and `npm test`.
